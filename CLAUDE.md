# Diese Library: Plugwise  

- Diese Library dient zur Anbindung von Plugwise-Geräten, an die Software IP-Symcon. Sie stellt die notwendigen Module und Funktionen bereit, um Plugwise-Geräte in IP-Symcon zu integrieren und zu steuern.
- Die Library ist so konzipiert, dass sie leicht erweiterbar ist.
- Quellen welche für die Entwicklung genutzt wurden sollen, aber bisher nicht genutzt wurden.
  - https://github.com/topics/plugwise
